### 🚀 What I've built

- **[Interview Copilot](https://github.com/AryanMaurya01/ai-interview-copilot)**: AI interview practice with voice mode. Whisper transcribes answers and an LLM scores them.
- **[QuantTrader AI](https://github.com/AryanMaurya01/QuantTrader_Ai)**: NIFTY 50 paper trading. Indicators generate the signals, the LLM only explains them, and a backtester reports Sharpe and drawdown.
- **[CNC Predictive Maintenance](https://github.com/AryanMaurya01/Edge-Based-Predictive-Maintenance-System-for-CNC-Machines)**: anomaly detection and health scoring from multi-sensor machine data, with a live dashboard.
- **[Code Review Agent](https://github.com/AryanMaurya01/code-review-agent)**: experimental agent that reviews GitHub PRs for bugs, security and performance issues.
- **[Trader Performance Analysis](https://github.com/AryanMaurya01/trader-performance-analysis)**: how Bitcoin market sentiment relates to trader profitability.
